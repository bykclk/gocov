Ignored files

{{with .Repo.IgnorePaths}}{{len .}} pattern{{if ne (len .) 1}}s{{end}}{{else}}None{{end}}

Files matching these patterns are left out of every report — generated code, mocks, a dev harness — before totals, diff coverage and the gate are computed. One pattern per line, matched at any directory level of the paths shown in reports: * stays within one directory, ** crosses them, a directory covers everything under it, and a leading / pins the pattern to the root.

A pattern matching every file is refused at upload time rather than landing a 0% report.
{{if $ro}}Owners set the ignore patterns.{{else}} Applies to uploads received from now on. Past reports keep their numbers.{{end}}
