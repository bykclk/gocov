Get coverage flowing

Workspace {{.Workspace.Prefix}} on {{.ForgeLabel}} · Settings

1. Set the CI variables

{{if eq .Workspace.Forge "github"}}

In your GitHub org or repo: Settings → Secrets and variables → Actions. Add GOCOV_SERVER as a variable and GOCOV_TOKEN as a secret:

{{else}}

In Bitbucket: Workspace settings → Workspace variables. Add both, marking GOCOV_TOKEN as secured:

{{end}} 
GOCOV_SERVER={{.BaseURL}}
GOCOV_TOKEN={{.Workspace.Token}}

2. Add the upload step

{{if eq .Workspace.Forge "github"}}

In your GitHub Actions workflow, after the tests:

- run: go test ./... -covermode=atomic -coverprofile=coverage.out
- run: go run github.com/bykclk/gocov/cmd/gocov@latest upload coverage.out
  env:
    GOCOV_SERVER: ${{"{{"}} vars.GOCOV_SERVER {{"}}"}}
    GOCOV_TOKEN: ${{"{{"}} secrets.GOCOV_TOKEN {{"}}"}}
{{else}}

In bitbucket-pipelines.yml, after the tests:

- step:
    script:
      - go test ./... -covermode=atomic -coverprofile=coverage.out
      - go run github.com/bykclk/gocov/cmd/gocov@latest upload coverage.out
{{end}}

Commit, branch, repo and PR are auto-detected; other languages can upload lcov, JaCoCo or Cobertura with -format.

3. Push a commit

Repos under {{.Workspace.Prefix}}/ register themselves on their first upload — nothing else to configure.
